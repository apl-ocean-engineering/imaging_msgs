# imaging_msgs

This repo defines generic messages related to the operation of imaging sensors (cameras) in ROS.

`main` is the preferred branch.  This branch contains a ROS1/ROS2 message package and should build in both ROS1 and ROS2 workspaces.

To not break existing workflows, two "legacy" branches are retained, but references to these branches should be updated to `main`

* `ros1` for ROS1 melodic and noetic
* `ros2` for ROS2 humble and iron
